# 鹈鹕骑车

一只围着红围巾的白鹈鹕，骑着薄荷绿复古单车，沿海边木栈道一路向前。

单个 HTML 文件（SVG + 原生 JavaScript），没有任何依赖，用浏览器直接打开 `index.html` 就能看。

## 操作

| 动作 | 键盘 | 鼠标 / 触屏 |
| --- | --- | --- |
| 暂停 / 播放 | 空格 | 底部播放按钮 |
| 调速 | ← → | 底部滑块 |
| 按铃 | B | 铃铛按钮，或点车把上的铃 |
| 吃鱼 | F | 鱼按钮，或点车筐 |
| 跳一下 | J | 点单车 |
| 昼夜切换 | N | 月亮 / 太阳按钮（系统深色模式下默认是夜晚） |
| 逗一下鹈鹕 | | 点鹈鹕 |

## 细节

- 两条腿用两段式反向运动学（IK）求解，脚一直踩在踏板上；轮子、曲柄、链条、飞轮按传动比联动。减速时会停止蹬踏滑行，并把踏板停在水平位置。
- 围巾是 Verlet 布料模拟，受风、重力影响，跳跃时近乎失重；头部和喉囊用弹簧阻尼，会随蹬车的起伏晃动。
- 多层视差背景：云、远处海岬和灯塔、帆船、海浪、沙滩、木栈道、前景沙丘，场景物件随机循环生成。
- 黄昏和夜晚整体换色：落日、月亮、星星、流星、路灯、车灯、灯塔光束、发光的浪花。
- 隔一阵会自己从车筐叼鱼抛起来吃掉；也会有螃蟹爬上栈道，鹈鹕连人带车跳过去。
- 铃声和吞咽声用 Web Audio 实时合成，只在你点按之后才会发声。
- 辐条和木板有运动模糊；物理用固定子步长，在 30 / 60 / 144 Hz 屏幕上表现一致。
